# NewChatLearning 首个 Beta 验收标准

## 发布要求

更新日志与 Release Notes 只描述社区用户可观察的功能、修复和兼容性变化，不记录开发过程、实现参考、本机路径、测试群号、账号或部署环境的个性化配置操作。

NewChatLearning 使用两级验收门槛：

1. **公开预览 Beta**：允许发布经过安装、核心 WebUI、旧词库迁移、备份和自动测试验证的预发布版本。发布说明必须列出未完成的实机项目，不得宣称稳定、生产可用或完整达到原版兼容。
2. **完整兼容 Beta**：原版功能、消息兼容、现代增强、安全与恢复四个方面完成 Windows + AstrBot + NapCat + QQ 群实测后，才可宣称完成首个完整兼容 Beta。

下方未勾选项目继续作为完整兼容 Beta 的验收清单，不阻止明确标记限制的公开预览版发布。

### TTS

#### Beta 31 云端 TTS

- 云端驱动默认关闭；启用后才会发起付费请求，核心学习与回复路径不调用 LLM。
- 支持火山引擎、阿里云、腾讯云、Azure、OpenAI、OpenAI 风格接口及自定义 HTTPS HTTP 映射。
- 云端密钥使用 Windows 当前用户 DPAPI 保存，WebUI 仅显示已配置状态与掩码，不回显明文。
- 默认额度为每分钟 10 次、每日 200 次、每日 50,000 字符；请求发出前预留额度，超限拒绝。
- 自定义 HTTP 仅允许受限 JSON 映射和 Base64 音频字段；禁止明文 HTTP、代理、重定向及非音频响应。

Beta 31.post1 修复 AstrBot 4.27.2 配置 schema 兼容性：自定义 HTTP 的请求头与请求体映射使用平台原生 `dict` 类型，避免插件加载时把无子项的 `object` 递归解析并触发 `KeyError: 'items'`。

Beta 31.post2 补齐云端 TTS WebUI：提供全部云端驱动、模型与区域、应用参数、调用额度、自定义 HTTP JSON 映射、DPAPI 密钥状态与管理；切换驱动时更新默认接口并显示对应密钥字段。云端测试和密钥变更要求二次确认，页面刷新不重新加载或重新登录。自定义 HTTP 映射可通过 `${secret.<名称>}` 引用 DPAPI 密钥，配置中不保存密钥明文。

- [x] Windows 本地、GPT-SoVITS、通用本地 HTTP（离线测试通过；Windows `System.Speech` 已完成本机真实 WAV 冒烟测试，NapCat 语音发送待实机验收）。
- [x] 火山、阿里、腾讯、Azure、OpenAI、OpenAI 风格和自定义 HTTP 映射（驱动、签名/请求构造和配置页面已离线验证；真实付费账户调用待维护者自备凭据验收）。
