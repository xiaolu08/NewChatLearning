# NewChatLearning 首个 Beta 验收标准

## 发布要求

首个可运行 Beta 只有在原版功能、现代增强、安全与恢复四个方面全部通过后才算完成。单元测试通过但未在 Windows + AstrBot + NapCat + QQ 群实测的项目不能发布为首个 Beta。

## 验收清单

### 原版兼容

- [ ] 相邻消息问答链、超时重开链、同一成员连续消息。
- [ ] 学习/回复总开关和群列表。
- [x] 分群、实时全局联合、排除全局、群标签（离线测试通过，仍待实机与大词库验收）。
- [x] 精确、正则、jieba 余弦匹配及阈值（离线测试通过，仍待实机验收）。
- [x] 答案重复权重随机、类型阈值、概率、等待、冷却、长度限制（离线测试通过，仍待实机验收）。
- [ ] @触发、文本占位格式化和消息链回复。
- [ ] 过滤、敏感词、黑名单容错、自动清理（回复过滤、敏感计数、阈值拉黑、全局/分群作用域、人工解封和管理员主动过滤清理已离线测试；无人值守定时清理及实机验收未完成）。
- [ ] 管理模式：搜索、查看、删除、自定义问答和权重（文本/正则短命令已离线测试；媒体问答、批量管理和实机验收待完成）。
- [x] 快速删除与回复记录（离线测试通过，仍待 NapCat 实机验收发送回执、引用和撤回）。
- [ ] 定时任务与原版特殊发送动作。
- [ ] 语音回复、概率、音色/模型选择。
- [ ] 导入词库、统计检查、Excel 导出。
- [ ] 原版命令别名与帮助行为。

### 消息兼容

- [ ] 文本、图片、闪照、普通/商城表情、@、引用、语音（核心类型已离线测试，商城表情和实机验收未完成）。
- [ ] 转发、App、XML、JSON、文件、音乐分享、骰子、视频。
- [ ] 媒体下载、哈希去重、重发、过期降级和配额超限（核心路径、只读健康扫描和两阶段清理已离线测试；主动远程探测、备份恢复 UI 和实机验收未完成）。
- [x] 三份共享 `.cl` 均可扫描并生成准确报告（隔离扫描与离线样本已验证；导入仍待实现）。
- [x] 至少一份共享词库可受限导入；失效媒体不导致崩溃（2.1 MB 共享词库已完成临时库导入，数据库与备份完整性为 `ok`；旧媒体有效性报告待继续完善）。

### 新增能力

- [ ] 静默学习群绝不自动词库回复，管理员命令仍可用（离线配置与回复路径已验证，待 NapCat 实机验收）。
- [ ] 定向用户学习只采集目标用户的紧随答案（离线相邻消息链、非目标跳过与目标固化已验证，待 NapCat 实机验收）。
- [ ] 自身回复与管理命令不学习；其他 QQ Bot 消息可学习。
- [ ] 撤回尚未固化消息可修复学习链。
- [ ] 按成员删除贡献并自动备份。
- [ ] 命中发送后停止当次 LLM；下一次 LLM 可看到词库回复或明确报告兼容关闭原因。
- [ ] 普通成员插件命令全程静默（快速删除入口已覆盖，完整命令集待实现）。

### WebUI 与安全

- [ ] 首次强制设密、Argon2id/scrypt、登录限流、锁定、退出和改密（scrypt 路径已离线测试；AstrBot 实机和 Argon2id 可选路径待完成）。
- [ ] CSRF、会话 Cookie、无缓存、安全响应头和危险操作再认证（认证基础、媒体清理及词库删除再认证已离线测试；其他危险操作和实机验收待完成）。
- [ ] 默认本机访问，局域网模式需显式开启。
- [ ] 概览、群目标、词库、媒体、过滤、权限、TTS、任务、备份、审计页面可用（概览、群聊与定向目标、文本/正则词库、媒体清理、过滤规则测试和黑名单管理页已实现；桌面/移动离线验收持续执行）。
- [ ] WebUI、AstrBot 配置和命令同步，无静默覆盖冲突。
- [ ] DPAPI 密钥加密、掩码显示、日志和备份不泄密。

### TTS

- [ ] Windows 本地、GPT-SoVITS、通用本地 HTTP。
- [ ] 火山、阿里、腾讯、Azure、OpenAI、OpenAI 风格和自定义 HTTP 映射。
- [ ] 云端默认关闭、费用警示、频率/每日额度、超时和错误脱敏。

### 可靠性

- [ ] 10 万问题/30 万答案级导入和查询基准满足可接受响应时间。
- [ ] AstrBot 重载、插件重载、NapCat 断线重连不损坏学习链或数据库。
- [ ] SQLite 事务、迁移、备份校验、恢复预览和回滚可用。
- [ ] 媒体达到 10 GB 配额时文本学习继续，旧媒体不自动丢失。
- [ ] 所有高风险操作有审计记录。

当前媒体流程已验证本地健康文件、缺失文件、路径越界、哈希不一致、旧远程 URL、混合答案影响计算、扫描不删除答案、默认裁剪、显式整条删除、空问题清理、重复答案合并、操作者绑定、陈旧计划拒绝、备份完整性和审计。主动远程可用性探测、备份恢复入口与 NapCat 实机验收仍未完成，因此不能视为媒体生命周期验收完成。

当前词库 WebUI 已离线验证登录隔离、CSRF 写保护、正则输入校验、群作用域、删除前密码再认证、备份完整性、审计保留与绝对路径脱敏。媒体问答编辑、批量操作和 AstrBot/NapCat 实机验收仍未完成。

当前群聊设置已离线验证五种群模式、定向用户归一化、AstrBot 配置对象异步持久化、保存失败回滚、revision 冲突拒绝、CSRF 和配置审计。真实 AstrBot Dashboard 与插件配置文件的双入口交替保存仍待实机验收，因此配置同步条目尚未勾选完成。

当前过滤流程已离线验证普通规则不阻止学习、敏感词计数、阈值消息不学习、封禁后持续排除、全局/分群隔离、候选在权重抽样前剔除、非法/超时正则容错、配置保存回滚与冲突、CSRF、无敏感正文命中日志以及人工封禁/解封审计。AstrBot/NapCat 实机消息组件和大词库规则性能仍待验收。

当前过滤词库清理已离线验证无正文预览、群与操作者绑定、一小时计划、配置 revision 变化拒绝、答案变化拒绝、执行前完整备份、单事务删除、回复追踪失效、空问题清理、最小化审计、CSRF、密码再认证和备份路径脱敏。该能力只允许管理员主动执行；无人值守定时删除仍未实现。
