# NewChatLearning 0.1.0-beta.31.post7

这是一个命令入口修复版本，面向 AstrBot 4.27.2 的 Beta 用户。

## 修复内容

- 管理员私聊 `!help`、全角 `！help` 和 `/ncl help` 现在会显示插件帮助。
- 普通成员触发管理帮助命令仍不会收到回复。

## 安装包

`NewChatLearning-0.1.0-beta.31.post7.zip`

本版本仍为 Beta 预发布版本，请在升级前保留现有词库备份。
