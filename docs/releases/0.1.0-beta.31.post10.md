# NewChatLearning 0.1.0-beta.31.post10

这是一个媒体回复稳定性修复版本，面向 AstrBot 4.27.2 的 Beta 用户。

## 修复内容

- 修复失效图片文件标识被误当作本地路径，导致回复处理抛出文件不存在错误的问题。
- 媒体无法恢复时，包含文本的回复仍会发送文本内容。
- 纯媒体且无法恢复时安全跳过，不再中断群消息处理。

## 安装包

`NewChatLearning-0.1.0-beta.31.post10.zip`

本版本仍为 Beta 预发布版本，请在升级前保留现有词库备份。
