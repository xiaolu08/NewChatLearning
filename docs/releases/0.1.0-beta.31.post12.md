# NewChatLearning 0.1.0-beta.31.post12

这是一个跨群词库范围管理更新，面向 AstrBot 4.27.2 的 Beta 用户。

## 更新内容

- 新增 `!add globe <群号...>`，允许指定回复群查询全局或标签共享词库。
- 新增 `!remove globe <群号...>`，将指定回复群限制为只查询本群词库。
- `!grouplist` 现在分别显示使用全局词库、仅使用本群词库和不汇入全局词库的群。
- `globe` 只控制目标回复群的查询范围；`unmerge` 继续控制来源群是否汇入全局词库。

## 安装包

`NewChatLearning-0.1.0-beta.31.post12.zip`

本版本仍为 Beta 预发布版本，请在升级前保留现有词库备份。
