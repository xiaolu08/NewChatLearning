# NewChatLearning 0.1.0-beta.31.post9

这是一个 NapCat 图片消息采集与媒体持久化修复版本，面向 AstrBot 4.27.2 的 Beta 用户。

## 修复内容

- 图片临时 URL 下载失败时，不再丢弃原始图片消息或问答关系。
- 按图片文件标识尝试调用 NapCat `get_image` / `get_file`，优先取得可长期保存的本地文件。
- NapCat 无法恢复媒体文件时仍保留原始图片组件，避免整条问答丢失。

## 安装包

`NewChatLearning-0.1.0-beta.31.post9.zip`

本版本仍为 Beta 预发布版本，请在升级前保留现有词库备份。
