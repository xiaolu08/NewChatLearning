# NewChatLearning 0.1.0-beta.31.post19

这是面向 AstrBot 4.27.2 Beta 用户的跨群回复策略增强版本。

## 更新内容

- 新增 `!reply -s <百分比> <群号...>`，从管理员私聊或任意管理群设置目标群独立回复概率。
- 新增 `!reply -d <群号...>`，删除目标群独立概率并恢复继承全局概率。
- `!grouplist` 展示已配置的独立回复概率。
- WebUI 群聊设置增加本群回复概率覆盖项，留空即可恢复继承。
- 实际回复决策、聊天命令和 WebUI 统一读取同一份配置服务。

## 安装包

`NewChatLearning-0.1.0-beta.31.post19.zip`

本版本仍处于 Beta 阶段，升级前请保留现有词库数据库备份。
