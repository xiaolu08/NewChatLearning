# NewChatLearning 0.1.0-beta.31.post14

这是面向 AstrBot 4.27.2 Beta 用户的兼容性修复版本。

## 修复内容

- 修复包含失效图片、语音、视频或文件引用的回复在 NapCat 发送阶段失败时抛出异常的问题。
- 混合文本与媒体的回复在媒体不可用时会保留文本内容并重试发送。
- 纯失效媒体回复会安全跳过，不再中断消息处理流水线。

## 安装包

`NewChatLearning-0.1.0-beta.31.post14.zip`

本版本仍处于 Beta 阶段，升级前请保留现有词库数据库备份。
