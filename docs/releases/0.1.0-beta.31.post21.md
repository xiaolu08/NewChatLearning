# NewChatLearning 0.1.0-beta.31.post21

本次更新把导入的旧 `.cl` 文件升级为可独立管理的外部词库来源。

## 更新内容

- 新导入词库不再与群聊自产问答混合，而是保存到独立词库作用域。
- 外部词库可绑定一个或多个 QQ 群，并且只在已绑定群的回复检索中生效。
- 支持单独启用和停用；停用不会删除词条。
- 支持上传新 `.cl` 文件完整替换同一词库，保留词库 ID、绑定范围并增加版本号。
- 支持删除外部词库；执行前自动创建 SQLite 备份，只删除对应外部来源。
- WebUI 迁移页新增名称、导入/更新模式、状态、版本、绑定群和管理操作。
- 所有启停、绑定、更新和删除操作写入脱敏审计日志。

## 兼容说明

旧版本已经合并进群聊词库的导入内容缺少可靠来源边界，无法安全地自动拆分。本版本会继续保留这些历史数据，但不会将其显示为可独立删除的外部词库。重新上传原文件可建立新的独立外部词库。

## 验证

- SQLite schema：v11
