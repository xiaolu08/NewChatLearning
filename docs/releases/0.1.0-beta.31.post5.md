# NewChatLearning 0.1.0-beta.31.post5

本次 Beta 更新恢复 ChatLearning 原版跨群管理命令，并按消息场景区分全局主开关与当前群开关。

## 主要变化

- 管理员私聊 `!learning`、`!reply` 时切换全局学习或回复主开关。
- 群聊中发送 `!learning`、`!reply` 时继续切换当前群能力。
- 恢复 `!grouplist` 与 `!add/!remove learning|learnings|reply|tag|subadmin|unmerge` 跨群管理命令。
- 跨群命令可从管理员私聊或任意管理群发送，不需要进入目标群。
- `!add subadmin` 通过 NapCat/AstrBot 读取目标群当前群主和群管理员。
- 配置更新使用 revision 冲突保护、整批回滚和审计记录。

## 安装包

`NewChatLearning-0.1.0-beta.31.post5.zip`

当前版本仍是 Beta，NapCat 私聊事件、目标群资料读取和真实跨群配置保存需要继续实机验收。
