# NewChatLearning 0.1.0-beta.31.post8

这是一个跨群管理命令稳定性修复版本，面向 AstrBot 4.27.2 的 Beta 用户。

## 修复内容

- 修复 `!add learning`、`!add learnings`、`!add reply` 及对应移除命令在 AstrBot 配置包装对象包含线程锁时失败的问题。
- 配置保存失败时仍会恢复修改前的数据。

## 安装包

`NewChatLearning-0.1.0-beta.31.post8.zip`

本版本仍为 Beta 预发布版本，请在升级前保留现有词库备份。
