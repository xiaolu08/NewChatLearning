# NewChatLearning 0.2.0-beta

## 2026-08-16 更新

- 新增按触发消息类型设置回复概率的跨群命令，并保留原有统一概率命令。
- 新增复读词库标签与每群滚动一小时两次的成功回复上限；复读候选仍执行正常概率判定。
- 修复带引用或 At 学到的问题无法被相同纯文本触发的问题。问题仍保留完整消息组件用于查看和管理，匹配时增加非正则问题的纯文本完全一致检查，不影响管理员启用 jieba 余弦相似匹配。
- 对齐原版相似匹配使用的标点忽略集合，并确保零相似度问题不会在阈值为零时被误选。

本次更新重做 NewChatLearning 内嵌 WebUI，使高频群聊管理、词库维护和运行检查更紧凑、更清晰。

## 更新内容

- 新增命名群聊联动词库，可使用 `!add/remove share <群号...> <联动组名>` 创建联动组并调整成员。
- 联动组只开放成员群的本群词库，不继承全局词库、外部导入词库或其他联动组权限。
- 新增管理员私聊 `!sharelist`；`!grouplist` 只显示查看引导，群聊不会披露联动组名或成员群号。
- 联动组支持自定义新成员欢迎语，可通过 `!add/remove wellcome` 或 WebUI 管理；首位新人入群后聚合 60 秒，期间新成员合并为一条 `@成员... + 文本` 消息，展示 60 秒后自动撤回。
- 联动组支持共享回复冷却，可通过 `!add reply cd <分钟> <联动组名>`、`!remove reply cd <联动组名>` 或 WebUI 管理；任一成员群成功回复后，全部成员群在设定时间内跳过词库回复，欢迎语不受影响。
- 使用固定侧栏组织概览、群聊、词库、过滤、权限、媒体、迁移、语音、任务、备份、诊断和审计模块。
- 每个模块显示独立页面标题和用途摘要，活动导航使用明确的强调轨道与可访问状态。
- 概览页突出运行状态，并统一问题、答案、待固化消息、媒体数量和媒体占用的数字层级。
- 统一按钮、输入框、选择器、表格、列表、提示信息和确认弹窗的视觉与键盘焦点反馈。
- 手机尺寸改用可关闭侧栏，切换模块后自动收起；长表单和表格保持局部滚动，不造成整页横向溢出。
- 支持减少动态效果偏好，禁用按钮与实际处理中按钮继续使用不同光标和状态反馈。
- 页面不依赖 CDN 或外部字体，保持 AstrBot 离线部署可用。

## 安全与兼容

- 继续使用无密码“进入”入口和一小时服务端管理会话。
- 页面内功能不要求密码；高风险操作继续使用二次确认、CSRF、配置 revision、备份和审计保护。
- 保留全部既有元素 ID、插件桥 API 路径和局部刷新行为。
- 当前仍为公开预览 Beta，建议升级后在 AstrBot 内嵌页逐项检查常用管理模块。
