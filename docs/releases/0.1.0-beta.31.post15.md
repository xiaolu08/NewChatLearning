# NewChatLearning 0.1.0-beta.31.post15

这是面向 AstrBot 4.27.2 Beta 用户的兼容性修复版本。

## 修复内容

- 修复图片、语音、视频、文件和 XML 等原始 OneBot 回复组件缺少 AstrBot 类型属性的问题。
- 修复上述回复发送后写入 AstrBot 本地消息历史时报错的问题。
- 保持本地回复可被后续会话历史与记忆插件识别。

## 安装包

`NewChatLearning-0.1.0-beta.31.post15.zip`

本版本仍处于 Beta 阶段，升级前请保留现有词库数据库备份。
