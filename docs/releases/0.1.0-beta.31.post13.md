# NewChatLearning 0.1.0-beta.31.post13

这是一个聊天帮助说明修复版本，面向 AstrBot 4.27.2 的 Beta 用户。

## 修复内容

- `/ncl help` 与管理员私聊 `!help` 分别展示 `!add globe` 和 `!remove globe`。
- 帮助文本明确 `globe` 控制目标群查询范围，`unmerge` 控制来源群汇入范围。
- `!grouplist` 的说明补充词库范围群列表。

## 安装包

`NewChatLearning-0.1.0-beta.31.post13.zip`

本版本仍为 Beta 预发布版本，请在升级前保留现有词库备份。
