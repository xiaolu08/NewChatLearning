# NewChatLearning 0.1.0-beta.31.post16

这是面向 AstrBot 4.27.2 Beta 用户的 NapCat 消息兼容性增强版本。

## 更新内容

- 补强图片、视频、语音、文件、商城表情、JSON、XML 和合并转发消息的原始 OneBot 段补全。
- AstrBot 预处理丢失媒体组件时，使用原始消息段继续进入 NewChatLearning 的学习与匹配流程。
- NapCat 媒体查询改为优先寻找本地文件；只有找不到本地文件时才保留远程 URL。
- 支持从 `get_image`、`get_video`、`get_record` 和 `get_file` 等接口尝试恢复媒体。

## 安装包

`NewChatLearning-0.1.0-beta.31.post16.zip`

本版本仍处于 Beta 阶段，升级前请保留现有词库数据库备份。
