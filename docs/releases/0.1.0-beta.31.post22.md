# NewChatLearning 0.1.0-beta.31.post22

本次更新重做 NewChatLearning 内嵌 WebUI，使高频群聊管理、词库维护和运行检查更紧凑、更清晰。

## 更新内容

- 使用固定侧栏组织概览、群聊、词库、过滤、权限、媒体、迁移、语音、任务、备份、诊断和审计模块。
- 每个模块显示独立页面标题和用途摘要，活动导航使用明确的强调轨道与可访问状态。
- 概览页突出运行状态，并统一问题、答案、待固化消息、媒体数量和媒体占用的数字层级。
- 统一按钮、输入框、选择器、表格、列表、提示信息和确认弹窗的视觉与键盘焦点反馈。
- 手机尺寸改用可关闭侧栏，切换模块后自动收起；长表单和表格保持局部滚动，不造成整页横向溢出。
- 支持减少动态效果偏好，禁用按钮与实际处理中按钮继续使用不同光标和状态反馈。
- 页面不依赖 CDN 或外部字体，保持 AstrBot 离线部署可用。

## 安全与兼容

- 继续使用无密码“进入”入口和一小时服务端管理会话。
- 页面内功能不要求密码；高风险操作继续使用二次确认、CSRF、配置 revision、备份和审计保护。
- 保留全部既有元素 ID、插件桥 API 路径和局部刷新行为。
- 当前仍为公开预览 Beta，建议升级后在 AstrBot 内嵌页逐项检查常用管理模块。
