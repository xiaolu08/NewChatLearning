# NewChatLearning 0.1.0-beta.31.post20

这是面向 AstrBot 4.27.2 Beta 用户的跨群管理信息保护版本。

## 修复内容

- 群聊中的跨群管理写入回执只显示操作结果和目标数量。
- 群聊中的 `!grouplist` 只展示当前群的学习、回复、独立概率和词库范围状态。
- 群聊回执不再列出其他群号、其他群的独立概率或完整配置。
- 管理员私聊继续提供完整跨群配置，便于集中管理。

## 安装包

`NewChatLearning-0.1.0-beta.31.post20.zip`

本版本仍处于 Beta 阶段，升级前请保留现有词库数据库备份。
