# NewChatLearning 0.1.0-beta.31.post4

这是 NewChatLearning 的首个公开预览版本。它将 ChatLearning 的零 LLM Token 学习与回复核心移植到 AstrBot + NapCat + OneBot v11 + QQ 群环境，目标平台为 Windows。

## 安装

在 AstrBot Dashboard 的插件管理页面选择从本地 ZIP 安装：

`NewChatLearning-0.1.0-beta.31.post4.zip`

安装后打开插件内嵌 WebUI，点击“进入”建立一小时管理会话，无需输入 NewChatLearning 独立密码。

## 主要功能

- 相邻消息学习、精确/正则/本地相似度匹配和答案权重。
- 分群词库、静默学习、定向学习、内容过滤和黑名单。
- 图片、语音、视频、文件、商城表情、XML 和转发等消息组件处理。
- 旧 `.cl` 词库隔离扫描、群绑定导入计划、自动备份和统计核对。
- WebUI 词库、媒体、权限、迁移、TTS、任务、备份、审计和诊断工具。
- Windows 本地 TTS、GPT-SoVITS、通用本地 HTTP TTS 和可选云端 TTS。

## 重要修复

- 清理旧版 `webui-password.json`，取消独立密码输入。
- 保留一小时服务端会话、CSRF、高风险操作二次确认和审计。
- 修复 AstrBot 热更新时旧版 `new_chat_learning.*` 模块缓存导致的前后端认证错配。
- 页面检测到前后端版本不一致时停止请求，避免触发 AstrBot 平台登录跳转。

## 已知限制

- 仅支持 Windows + AstrBot 4.27.2+ + NapCat + OneBot v11 + QQ 群。
- 完整 NapCat 消息类型、长时间任务、大规模词库和全部管理页面仍需社区实机验证。
- 词库媒体问答人工编辑和批量操作暂不纳入当前产品范围。
- 云端 TTS 默认关闭；启用真实服务商可能产生费用，需用户自行配置和验收。
