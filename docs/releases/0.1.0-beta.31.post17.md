# NewChatLearning 0.1.0-beta.31.post17

这是面向 AstrBot 4.27.2 Beta 用户的消息组件去重修复版本。

## 修复内容

- 修复原始 OneBot 消息补全时文本与 QQ 表情组件被重复追加的问题。
- 修复学习到的文本答案可能包含两份相同内容，导致 Bot 重复发送的问题。
- 组件合并现在按类型和数量抵消 AstrBot 已解析内容，仅补充真正缺失的媒体与长尾组件。

## 安装包

`NewChatLearning-0.1.0-beta.31.post17.zip`

本版本仍处于 Beta 阶段，升级前请保留现有词库数据库备份。
