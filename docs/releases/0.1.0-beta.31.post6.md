# NewChatLearning 0.1.0-beta.31.post6

这是针对 `0.1.0-beta.31.post5` 的 AstrBot 4.27.2 加载热修复。

## 修复内容

- 将私聊事件过滤器从不存在的 `EventMessageType.FRIEND_MESSAGE` 修正为 AstrBot 4.27.2 支持的 `EventMessageType.PRIVATE_MESSAGE`。
- 保留平台消息层的好友/私聊映射，不改变管理员私聊全局开关和群聊当前群开关语义。
- 使用实际 AstrBot `.venv` 验证插件入口模块可导入。

## 安装包

`NewChatLearning-0.1.0-beta.31.post6.zip`

`post5` 会在插件导入阶段失败，不建议继续安装。请升级至本版本。
