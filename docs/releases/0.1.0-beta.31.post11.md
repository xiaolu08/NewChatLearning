# NewChatLearning 0.1.0-beta.31.post11

这是一个 OneBot 媒体消息重发稳定性修复版本，面向 AstrBot 4.27.2 的 Beta 用户。

## 修复内容

- 图片、语音和视频消息同时包含文件标识与临时 URL 时，优先使用文件标识重发。
- 过期临时 URL 不再被强制下载为 Base64。
- 媒体解析失败时不会中断包含文本的整条回复。

## 安装包

`NewChatLearning-0.1.0-beta.31.post11.zip`

本版本仍为 Beta 预发布版本，请在升级前保留现有词库备份。
