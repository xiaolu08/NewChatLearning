# NewChatLearning WebUI 与安全规范

## 摘要

WebUI 是完整管理面，不是单纯配置表。界面采用紧凑的运维后台结构，所有配置与 AstrBot 插件配置共享同一服务。默认仅本机访问且必须登录；局域网访问需要显式开启，项目不提供直接公网暴露模式。

## 安全设计

### 页面结构

| 页面 | 主要内容 |
| --- | --- |
| 概览 | 问题/答案/组件量、今日学习、命中率、回复量、媒体占用、错误、当前学习目标 |
| 群与目标 | 群模式、静默学习、定向用户、标签、保留期、单群覆盖 |
| 词库 | 搜索、问答详情、权重、编辑、删除、自定义回复、批量操作 |
| 导入导出 | `.cl` 安全扫描、迁移预览、JSONL/CSV/Excel、报告 |
| 媒体 | 配额、类型统计、健康扫描、失效预览、清理和去重 |
| 过滤与黑名单 | 规则、作用域、测试、命中记录、解除 |
| 权限 | 插件管理员、群子管理员、权限矩阵 |
| 语音 | 驱动、密钥、音色、额度、健康检查和测试合成 |
| 定时任务 | 可视化计划、动作、执行历史和失败重试 |
| 备份恢复 | 自动/手动备份、校验、恢复预览 |
| 审计与诊断 | 登录、配置、删除、导入、错误、兼容状态、脱敏诊断包 |

### 认证

- 首次使用必须设置独立管理密码，不提供空密码或默认密码。
- 密码使用 Argon2id；依赖不可用时使用 scrypt，不回退 MD5/SHA1。
- 会话使用随机服务端令牌，Cookie 设置 `HttpOnly`、`SameSite=Strict`；局域网 HTTP 下不虚假设置不可用的 Secure，界面持续提示风险。
- 所有修改 API 要求 CSRF Token；登录、退出、改密和恢复会使旧会话失效。
- 登录按 IP 和账户限流，连续失败临时锁定；响应不泄露账户或配置状态。
- 清空、批量删除、恢复备份、导入合并和密钥变更要求重新输入密码。

### 网络

- 默认绑定 `127.0.0.1`。
- 开启局域网后绑定管理员指定地址，显示当前可访问地址和风险提示。
- 不提供一键公网监听；不默认信任 `X-Forwarded-For` 等代理头。
- 所有页面设置 `no-store`、合理 CSP、`X-Content-Type-Options` 和 frame 限制。

### 密钥

- 云端 TTS 密钥使用当前 Windows 用户或机器范围 DPAPI 加密后落盘。
- WebUI 只显示末尾少量字符，API 永不返回可解密密文。
- 普通备份不包含密钥；加密密钥备份也不承诺跨机器恢复。
- 日志、异常、健康检查和诊断包必须脱敏请求头与请求体字段。

### 配置一致性

- WebUI、AstrBot 配置页和聊天命令调用同一配置服务。
- 每次保存携带版本号；版本落后时返回冲突并要求刷新。
- 保存记录来源、操作者、旧值摘要、新值摘要和时间。
