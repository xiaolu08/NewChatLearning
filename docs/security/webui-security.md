# NewChatLearning WebUI 与安全规范

## 摘要

WebUI 是完整管理面，不是单纯配置表。界面采用紧凑的运维后台结构，所有配置与 AstrBot 插件配置共享同一服务。默认仅本机访问且必须登录；局域网访问需要显式开启，项目不提供直接公网暴露模式。

## 安全设计

### 页面结构

| 页面 | 主要内容 |
| --- | --- |
| 概览 | 问题/答案/组件量、今日学习、命中率、回复量、媒体占用、错误、当前学习目标 |
| 群与目标 | 群模式、静默学习、定向用户、标签、保留期、单群覆盖 |
| 词库 | 搜索、问答详情、权重、编辑、删除、自定义回复、批量操作 |
| 导入导出 | `.cl` 安全扫描、迁移预览、JSONL/CSV/Excel、报告 |
| 媒体 | 配额、类型统计、健康扫描、失效预览、清理和去重 |
| 过滤与黑名单 | 规则、作用域、测试、命中记录、解除 |
| 权限 | 插件管理员、群子管理员、权限矩阵 |
| 语音 | 驱动、密钥、音色、额度、健康检查和测试合成 |
| 定时任务 | 可视化计划、动作、执行历史和失败重试 |
| 备份恢复 | 自动/手动备份、校验、恢复预览 |
| 审计与诊断 | 登录、配置、删除、导入、错误、兼容状态、脱敏诊断包 |

### 认证

- 首次使用必须设置独立管理密码，不提供空密码或默认密码。
- 管理密码最少 8 个字符、最多 256 个字符；已有更长密码不受影响。
- 密码使用 Argon2id；依赖不可用时使用 scrypt，不回退 MD5/SHA1。
- 会话使用随机服务端令牌，Cookie 设置 `HttpOnly`、`SameSite=Strict`；局域网 HTTP 下不虚假设置不可用的 Secure，界面持续提示风险。
- 所有修改 API 要求 CSRF Token；登录、退出、改密和恢复会使旧会话失效。
- 登录按 IP 和账户限流，连续失败临时锁定；响应不泄露账户或配置状态。
- 登录会话固定有效一小时；会话内管理功能不重复要求密码。
- 清空、批量删除、恢复备份、导入合并、权限和密钥变更要求明确二次确认；服务端同时校验有效会话、CSRF 与确认标记。

### 网络

- 默认绑定 `127.0.0.1`。
- 开启局域网后绑定管理员指定地址，显示当前可访问地址和风险提示。
- 不提供一键公网监听；不默认信任 `X-Forwarded-For` 等代理头。
- 所有页面设置 `no-store`、合理 CSP、`X-Content-Type-Options` 和 frame 限制。

### 密钥

- 云端 TTS 密钥使用当前 Windows 用户或机器范围 DPAPI 加密后落盘。
- WebUI 只显示末尾少量字符，API 永不返回可解密密文。
- 普通备份不包含密钥；加密密钥备份也不承诺跨机器恢复。
- 日志、异常、健康检查和诊断包必须脱敏请求头与请求体字段。

### 配置一致性

- WebUI、AstrBot 配置页和聊天命令调用同一配置服务。
- 每次保存携带版本号；版本落后时返回冲突并要求刷新。
- 保存记录来源、操作者、旧值摘要、新值摘要和时间。

## 当前实现

Beta 13 已为 AstrBot 嵌入式插件页面实现独立认证基础：首次设密只接受环回客户端地址，密码使用标准库 `scrypt` 与随机盐持久化；会话令牌和 CSRF 令牌由服务端随机生成并只保存在内存中，插件重载会使会话失效。Cookie 使用 `HttpOnly`、`SameSite=Strict`，所有认证和状态 API 返回 `no-store`、CSP、防嵌入、MIME 防嗅探和无引用来源头。

登录按客户端地址和全局账户窗口累计失败次数，达到阈值后临时锁定。设密、登录成功/失败、改密和退出写入不含密码内容的审计记录；密码文件损坏时认证关闭并返回受控错误。页面由 AstrBot Dashboard 承载，因此当前监听地址仍由 AstrBot 决定；插件不信任代理转发头，也不把“嵌入式页面”描述成独立公网服务。

Beta 14 的媒体清理执行要求有效会话、CSRF、绑定当前登录会话的短期清理计划和明确二次确认。审计和计划只保存会话令牌的短摘要标识，不保存令牌本身。API 只向页面返回备份文件名，不返回插件数据目录的绝对路径。媒体页可按群执行健康扫描、影响预览、默认组件裁剪或显式整条答案删除；执行仍复用数据库备份、单事务校验和审计机制。

Beta 15 增加按群隔离的词库管理页：登录后可搜索问题并读取详情；新增文本/正则问答和修改权重还要求有效 CSRF；删除答案或整个问题还要求明确二次确认，并在删除前生成通过 SQLite `quick_check` 的数据库备份。路由在备份前验证目标确实属于所选群，跨群 ID 不可读取或修改；删除响应只返回备份文件名，不返回绝对路径。所有写入继续使用与聊天命令相同的应用服务和数据库审计。

Beta 16 增加群聊与学习目标管理。读取要求登录，保存要求 CSRF，并携带读取时的配置 revision；若 AstrBot 配置页或其他入口已完成更新，旧页面会收到冲突并要求刷新。保存直接使用 AstrBot 注入的插件配置对象及其持久化方法，持久化失败会回滚内存改动并返回受控错误。成功保存记录 WebUI 会话摘要、修改前后群设置与配置来源，不记录会话令牌。

Beta 17 增加过滤与黑名单管理。读取过滤设置、命中统计和黑名单要求登录；规则测试、保存、人工封禁和解封要求 CSRF。过滤命中表只保存群、用户标识、规则类型、方向和时间，不保存敏感消息正文；过滤配置审计只记录修改前后规则数量。人工黑名单操作记录作用域和群号，不记录触发内容。配置保存沿用 revision 冲突拒绝和失败回滚。

Beta 18 增加过滤规则词库清理。生成计划要求 CSRF，页面只获得汇总数量和规则类型分布，不获得命中答案正文或内部操作列表。执行要求明确二次确认；计划绑定会话操作者摘要、群号、配置 revision 和有效期，执行前备份并重新检查。备份绝对路径不返回页面，审计只记录计划 ID、群、删除数量、空问题数量和规则类型计数。

Beta 19 增加备份浏览、校验和恢复。列表与校验要求登录，只返回文件名、分类、大小、修改时间、完整性、schema 和表计数，不返回绝对路径。服务拒绝路径分隔符、目录穿越、非 `.sqlite3`、目录外符号链接、损坏数据库和未来 schema。恢复要求 CSRF 与明确二次确认；执行前生成当前数据库保险备份，恢复成功后清空全部服务端会话并删除当前 Cookie。恢复审计只保存候选文件名和保险备份文件名。

Beta 20 增加成员贡献清理。预览与执行均限定单个群和成员；计划绑定 WebUI 操作者摘要并在一小时后过期，返回及落盘计划只包含 ID、权重和汇总数字，不包含聊天正文。执行要求 CSRF 与明确二次确认，先创建完整数据库备份，再在单个事务内复核贡献次数和答案权重。共享答案只降低对应贡献权重，权重归零才删除答案；旧词库导入和管理员自定义问答没有成员归属，不参与删除。审计记录群、成员、计划 ID 和数量，不记录消息内容。

Beta 21 为概览页增加原地统计刷新。按钮只携带现有会话请求受保护的状态接口并更新页面字段，不调用登录状态接口、不重新加载页面，也不清空当前 WebUI 会话或其他模块的操作状态。

Beta 22 增加只读审计页。接口要求有效登录，按动作筛选并使用记录 ID 游标分页，单页限制 1 至 100 条。服务端不直接透传 `details_json`，只返回明确白名单字段；客户端 IP 显示为隐藏状态，WebUI 会话操作者统一显示为会话，不返回路径、聊天正文、密码、令牌、密钥或未知字段。页面全部通过文本节点渲染摘要。

Beta 23 将 WebUI 会话有效期统一为一小时。登录后所有管理功能不再重复要求当前密码；高风险操作保留二次确认弹窗，服务端要求布尔确认标记，并继续校验会话、CSRF、计划绑定、revision、备份和审计。权限页可管理插件管理员与按群子管理员，AstrBot 全局管理员始终优先；权限审计只记录修改前后管理员数量和群数，不记录 QQ 号清单。

Beta 24 增加语音管理页和本地 TTS 接口。读取与保存要求登录，保存和测试要求 CSRF，配置保存使用 revision 冲突保护；审计只记录启用状态和驱动变化。GPT-SoVITS 参考音频绝对路径不会由 Web API 返回，只显示是否已配置和文件名。通用 HTTP 与 GPT-SoVITS 只允许环回地址，禁用代理与重定向，限制超时、响应大小和音频格式。当前不接受云端驱动或 API 密钥，直到 DPAPI 存储与脱敏链完整实现。

Beta 26 增加当前群词库导出。导出确认使用现有一小时登录会话、CSRF 和明确二次确认，不重复要求密码。确认接口返回五分钟有效的一次性随机下载票据；票据绑定当前会话，下载仍要求登录，跨会话尝试不会消耗合法票据，成功下载后立即失效。CSRF 不进入下载 URL。导出文件只写入插件 `exports` 目录，生成依赖 SQLite 一致性快照，审计成功后才保留；审计仅记录群号、问题数、答案数和来源，不保存聊天正文或路径。XLSX 文本防公式注入，完整组件保存在 JSONL；导出包可能含个人信息，页面在确认前明确提示。

Beta 27 增加旧 `.cl` 迁移页。页面不接受服务器绝对路径，只通过 AstrBot 插件页原生单文件上传接口接收不超过 128 MB 的 `.cl` 文件。上传前需使用当前会话和 CSRF 取得五分钟随机授权票据；服务端使用随机文件名写入插件临时目录，校验净化后的原始文件名和实际字节数，再在独立进程执行 opcode 拒绝与受限反序列化扫描。未通过扫描的文件立即删除，浏览器只获得文件名、大小、结构计数和组件类型摘要，不获得路径或聊天正文。

通过扫描的上传记录绑定当前 WebUI 会话并在一小时后删除。转换计划进一步绑定当前会话和目标群，有效期一小时；执行要求有效会话、CSRF 和明确二次确认，先创建数据库备份，再以单事务合并旧词库。页面仅返回备份文件名。成功导入后删除 JSONL 暂存数据，已完成清单保留 30 天供当前会话查看；过期上传、计划和旧完成清单在后续迁移操作中清理。导入审计继续由数据库事务记录群号、来源文件名和数量，不记录路径或聊天正文。

Beta 28 增加登录保护的只读运行诊断页。运行计数仅以群号为键保存在内存中，记录固定事件和回复原因枚举及最后活动时间，插件重载后全部归零。数据库汇总只执行按群计数与权重聚合。API 明确不返回消息正文、用户 QQ、消息 ID、组件负载、凭据或文件路径；刷新只复用当前一小时会话，不重新验证密码或重新加载页面。

尚未实现持久化会话管理和局域网风险提示。当前密码使用 `scrypt`，符合规范中的依赖不可用回退路径；引入 Argon2id 前不会静默迁移或降低已有密码强度。
