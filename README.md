# NewChatLearning

> **Private Beta / 非正式项目**
>
> 当前仓库处于设计与开发准备阶段，尚未提供可安装、可运行的 AstrBot 插件。未经维护者明确确认，不应视为正式版本或生产可用项目。

NewChatLearning 计划将 [ChatLearning](https://github.com/JHue58/ChatLearning) 的完整用户可观察能力移植到 AstrBot，并以 Windows、AstrBot、NapCat 与 QQ 群作为首版运行环境。

## 核心目标

- 保留原版相邻群消息问答学习、加权回复、过滤、词库管理、标签、定时任务、语音和多媒体能力。
- 核心学习、匹配、选择和回复过程不调用 LLM，不主动产生模型 Token 费用。
- 支持静默学习、定向用户学习、媒体持久化、安全旧词库迁移和完整管理 WebUI。
- 本地词库回复成功后停止当次 LLM 流程，并尽可能同步到 AstrBot 后续会话历史。
- 首个可运行 Beta 必须通过完整功能验收，不以缺少原版能力的中间版本作为完成交付。

## 当前状态

当前已经完成：

- ChatLearning 原版源码与功能审计
- AstrBot 4.27.3 插件接口研究
- 三份共享 `.cl` 词库的非执行式结构检查
- 项目约定、数据模型、NapCat 消息兼容策略
- WebUI、安全、TTS 和首个 Beta 验收规格

下一阶段将建立 AstrBot 插件代码、SQLite 领域模型、NapCat 适配、管理 WebUI、TTS 驱动和迁移工具。

## 数据提醒

群聊词库可能包含个人信息、攻击性内容、政治内容和已经失效的媒体引用。共享 `.cl` 文件、运行数据库、媒体、备份、日志与密钥均被排除在版本控制之外，不会随仓库提交。
